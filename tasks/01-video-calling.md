# Feature 1 — Video Calling

## Sub-tasks

- [ ] 1.1 Set up room/session models, media signaling, and secure call join flow
  - Create call session schema, meeting IDs, participant status tracking, and secure access rules.
  - Validate reconnection and device switching readiness.

- [ ] 1.2 Implement one-to-one call UI and core controls
  - Add mute/unmute, camera toggles, leave/end call, participant list, and status badges.
  - Ensure mobile camera switch and connection-quality indicators work correctly.

- [ ] 1.3 Implement group call controls, host moderation, and in-call chat
  - Add host controls, co-host rights, participant permissions, screen share restrictions, and chat features.
  - Support raise hand, emoji, and message/file sharing.

- [ ] 1.4 Add reconnection resilience, permissions, recording, and low-bandwidth handling
  - Handle network interruptions, permission denial, background noise suppression, and max participant limits.
  - Add optional recording workflow and secure call recording access controls.
