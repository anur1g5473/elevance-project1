# Feature 6 — Multilingual Comments

- [ ] 6.1 Build comment schema, posting flow, editing rules, likes/dislikes, and sorting
  - Support comment creation, deletion window, likes/dislikes, replies, and newest/oldest/most-liked sorting.

- [ ] 6.2 Add replies, mentions, translation support, and report submission flow
  - Support @mentions, built-in translation, and flagging of inappropriate comments.
  - Preserve reply chains for deleted parent comments.

- [ ] 6.3 Implement spam/profanity moderation, rate limiting, and admin review
  - Detect abusive language, duplicates, malicious links, and comment flooding.
  - Record moderation logs and manage report history safely.
