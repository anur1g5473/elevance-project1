# Contributing

## Branch strategy

- Create feature branches from `main` using the convention:
  `feature/<feature-number>-<short-task-name>`

## Commit conventions

Use conventional commits such as:

- `feat:` for new features
- `fix:` for bug fixes
- `docs:` for documentation updates
- `test:` for tests
- `chore:` for project maintenance

## PR and review flow

1. Create a feature branch from `main`
2. Implement the task scope only
3. Run the relevant tests
4. Commit with a descriptive conventional message
5. Push the branch and create a pull request
6. Merge after review and verification
